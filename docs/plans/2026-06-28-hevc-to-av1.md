# HEVC → AV1 Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace HEVC with AV1 as Furnace's sole video output codec (NVENC hardware AV1 via NVEncC), keeping HDR10 static metadata and Dolby Vision (now Profile 10.1).

**Architecture:** In-place codec swap — no codec-abstraction layer. The single NVEncC encode path changes its codec/preset/DV-profile flags and QVBR anchors; the executor switches the encode intermediate from `video.mkv` (NVEncC self-mux) to a raw AV1 OBU elementary stream (`video.obu`) that mkvmerge muxes, so the DV RPU (a T.35 metadata OBU) survives. DV RPU extraction (from the still-HEVC source) is unchanged.

**Tech Stack:** Python 3.13, NVEncC (rigaya) ≥ 8.00, dovi_tool, mkvmerge ≥ v79; pytest + ruff + mypy via `make check`.

## Global Constraints

- **Calibration (verbatim):** NVEncC `--preset P4`; QVBR anchors `35 / 35 / 36 / 38 / 41` for SD(409 920) / 720p(921 600) / 1080p(2 073 600) / 1440p(3 686 400) / 4K(8 294 400) pixel-area. Preset and anchors move together.
- **AV1 codec flags:** `-c av1 --profile main --output-depth 10` — NO `--tier`, NO `--lookahead-level`. Keep `--tune uhq`, `--qvbr`, `--aq --aq-temporal`, `--lookahead 32`, `--multipass 2pass-quarter`, `--gop-len … --strict-gop --repeat-headers`.
- **Dolby Vision profile:** `8.1 → 10.1` (NVEncC `--dolby-vision-profile`; encoder-settings tag `dolby-vision=10.1`). RPU extraction (`dovi_tool`, `-m` mode) unchanged. NO AV1 `inject-rpu` step.
- **Version floor:** DV encodes require NVEncC ≥ 8.00 (gate is DV-conditional; non-DV AV1 not gated; unknown version not gated).
- **Encode intermediate:** non-passthrough → `video.obu`; passthrough → `video.mkv`.
- **HDR10** (`--master-display` / `--max-cll`) and **VMAF/SSIM** measurement: kept unchanged. **HDR10+**: still rejected (no change).
- **Version bump:** `furnace/__init__.py` and `pyproject.toml` → `2.0.0` (together).
- **Commits:** Per repo rules, NO per-task commits. Each task ends with `make check` green. A SINGLE commit happens only at the very end, after the review loop reaches zero AND the user explicitly authorises it. The "commit" is therefore not a task step here.
- **TDD, strict:** failing test before production code for every change; 100% line+branch coverage on touched code (`make check` enforces).
- **Tooling:** linters/tests ONLY via Makefile (`make lint`, `make typecheck`, `make test`, `make check`). Never call `uv run ruff/mypy/pytest` directly.

def _version_tuple(version: str) -> tuple[int, int] | None:
    """Parse 'MAJOR.MINOR' into a comparable (major, minor) tuple, or None."""
    m = re.match(r"(\d+)\.(\d+)", version)
